КАМЕНЬ-НОЖНИЦЫ-БУМ! v0.61 — комплект для заливки
================================================

1. Распакуйте архив в любую папку (любое имя, любые буквы).
2. Двойной щелчок по DEPLOY.bat.
   Дальше утилита задаст три вопроса — отвечайте «yes» (или просто Enter).
   При необходимости подтвердите заливку на телефоне.
   В конце она напечатает три адреса.
3. Скопируйте эти адреса в три поля URL:
   vk.com/app54845872 → Управление → «Размещение» → Сохранить.
4. Откройте https://vk.ru/app54845872 — в подвале меню должно быть v0.61.

Что в папке:
  DEPLOY.bat                          — заливка на хостинг VK (production)
  DEPLOY-DEV.bat                      — заливка только в dev-окружение
  START-HERE-IF-NOT-WORKING.txt       — если не получилось
  build\                              — сама игра (index.html, js, css, img)
  package.json, vk-hosting-config.json — настройки (app_id 54845872)
  tools\bump_version.py               — смена номера версии одной командой
  VERSION                             — 0.61

Новое в 0.61:
  - приглашение по уведомлению ВК сразу показывает окно «Вас зовут на партию»
    (даже если игрок в главном меню)
  - request_key читается через VKWebAppGetLaunchParams (в мобильном ВК его
    нет в адресе страницы)
  - срок жизни приглашения 45 минут вместо 10
  - кнопка «Проверить приглашения» в меню мультиплеера
